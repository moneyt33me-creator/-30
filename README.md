# Hoodie Promos Landing Page

Professional promotional graphics and videos for underground rappers.

## Features
- Hero section with high-impact tagline
- "How It Works" step-by-step guide
- Portfolio gallery with image and video assets
- Pricing section ($30 flat rate)
- Order intake form
- Mobile-first, responsive design with a dark hip-hop aesthetic

## Tech Stack
- HTML5
- CSS3 (Minified)
- Vanilla JavaScript (Minified)

## Development
Source files are located in `/home/team/shared/site/`. 
To build the production version, run the `deploy.sh` script in that directory.

## Deployment
Production files are served from the root of this repository.
